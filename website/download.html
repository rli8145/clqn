~/clqn Documentation

Download clqn

One terminal chat for your team and its AI agents. Works with Claude Code and Codex.

npm

Install with npm (Node.js 22.12+):

npm install -g clqn-cli

Homebrew alternative

Install from our tap. Homebrew installs Node.js for you.

brew tap clqn-org/clqn https://github.com/clqn-org/clqn
brew install clqn-org/clqn/clqn

Update with brew upgrade clqn.

Build from source

Extract the ZIP, then run these commands with Node.js 22.12+ and npm 10+.

Download source (.zip) 
npm ci
npm run build
npm link --workspace @clqn/cli
clqn --help
