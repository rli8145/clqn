# Changelog

[GitHub Releases](https://github.com/clqn-org/clqn/releases) holds the full release notes and installation archives. The entries below summarize published releases.

## [0.4.1](https://github.com/clqn-org/clqn/releases/tag/v0.4.1) · 2026-11-28

- Plan independent tasks in parallel with sub-orchestrators.
- Choose worker models by task and switch the orchestrator model during a session.
- Stop a running worker and continue the task on its existing branch.

## [0.4.0](https://github.com/clqn-org/clqn/releases/tag/v0.4.0) · 2026-11-26

- Pick a clan at launch, invite teammates from chat, and scroll with the mouse wheel.
- Nominate multiple backup hosts, or force-send a message to give it routing priority.
- Copy the GitHub sign-in code and use Codex or Claude Code executables ending in `.exe` or `.com` on Windows.

## [0.2.0](https://github.com/clqn-org/clqn/releases/tag/v0.2.0) · 2026-11-25

- Connect to the hosted server by default or remember a self-hosted endpoint. Teammates can join from a GitHub sign-in matching their invited email.
- Share chat, start connected Codex and Claude Code sessions, and publish worker pull requests from chat.
- Sync clean default-branch checkouts from GitHub notifications.

## [0.1.2](https://github.com/clqn-org/clqn/releases/tag/v0.1.2) · 2026-11-23

- Packaging release. See the linked release for the full comparison.

## [0.1.0](https://github.com/clqn-org/clqn/releases/tag/v0.1.0) · 2026-11-19

- First packaged release with the clqn CLI and its local stdio MCP server.
